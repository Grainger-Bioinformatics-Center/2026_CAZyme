# 2025_CAZyme
Genomic evidence for persisting saprotrophy in two lineages of primarily tropical lichenized fungi

Description for the Perl scripts:
cal_CAZy.pl                 Calculates the frequency of CAZyme annotations from input files and writes the results in a tab-delimited output file.
count_CAZy.pl           Counts the number of CAZy family annotations (AA, CBM, CE, GH, GT, PL) in Funannotate output files and writes the results to an output file.
extract_cazy_protein.pl     Extract the protein sequences from the CAZyme annotation list from Funannotate to a multifasta file with a list of CAZyme family (pec, lig, cel).
list_CAZy.pl             List and sort all the CAZyme family from the CAZyme annotation list Funannotate.
